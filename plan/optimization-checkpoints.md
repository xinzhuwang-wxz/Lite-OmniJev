# 进阶优化的阶段检查点

来源：原始方案第十一节；用户2026-10-14询问相应阶段是否处理。每到对应阶段逐项评审并记录决定，不漏项，不把检查点等同于自动启用全部探索。首发主线与阶段门槛优先；阶段5b及独立探索默认关闭。成熟工程优化可在既有范围内自主实施，额外GPU预算、推理定制或方向改变仍按用户授权边界处理。

| 检查时点 | 原方案项目 | 决策方式 |
|---|---|---|
| 阶段1 | A3 数字/日期前置计算 | 先验证确定性处理对数值/日期子集的收益、其他子集不退化，原预算<1 H100时；不为此改变官方模板契约或伪造事实。 |
| 阶段2 | A1 置换平均软标签；A5 对抗干扰项 | 主线数据/真值优先，先小对照；A1教师成本+40%必须纳入实测账，不默认为免费。 |
| 阶段3 | B3 自适应帧数/分辨率；A4 分模态LoRA | B3先同条件8/16帧主线对照，变帧策略为单独候选；A4仅旧模态下降>1pp时触发评审，不能先换训练主线。 |
| 阶段3→4 | A2 主动选题；R3 自适应帧数策略 | A2优先评估节约最大教师成本，比较同2万题与随机基线；R3须先有B3阈值基线，仍属可选探索。 |
| 阶段4之后 | A6 自蒸馏 | 独立探索默认关闭；已知真值优先，需封存汇总改善且ECE不退化，不能读取封存内容。 |
| 阶段5 | C1 共形集；C2 高可靠模式；C3 输入质量/OOD；C4 自适应温度；R1/R5 | 先完成主线置换/正反偏差/校准/弃权门槛。R1结论是阶段5主线要求，实验预算到阶段4实测复盘时安排；不得自动采用RL。其余候选按原成功/退出条件评估，R5先与校准阈值比较。 |
| 阶段6之前/阶段6 | B1 置信度级联；B2 早退出；B4 流式音频；B5 媒体编码缓存；B6 自动扇出；R2/R4 | B5等成熟工程项在服务瓶颈实测后优先；B1须保持准确率与成本门槛。B2涉及推理零定制例外，B4/R2/R4为可选探索，默认不启动。 |
| Playground/网关与阶段6 | D1 浏览器离线；D2 决策可视化；D3 MCP；D4 迁移报告 | D1先核验LiteRT Web可读logit，不能假定支持；D2共形/OOD依赖就绪后展示真实值；D3网关完成后评审；D4仅用户自供数据、不用于训练。新增可选产品能力不拖慢首发主线。 |

每次决定记录：触发实测、基线、原成功/退出阈值、依赖、预算与预计节省、启用/延后/放弃理由。GPU实验达到退出条件即停止，失败留证据。各项目原文细节与预算上限以HTML为准，以上表格不覆盖或降低原阈值。当前S0，本表仅登记未来检查点，没有启动第十一节实验。
