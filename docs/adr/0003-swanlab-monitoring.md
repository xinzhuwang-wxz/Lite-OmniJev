# ADR-0003：按用户要求采用 SwanLab 训练监控

状态：accepted；依据：用户2026-10-13提供SwanLab接入，指定Lite-OmniJev项目/maxen工作区。

替代原暂定MLflow，不同时维护两套监控。SDK作为monitoring可选依赖，版本与哈希随uv.lock；真实训练记录loss、学习率、梯度范数、步数，禁止上传示例随机指标冒充训练。
无卡鉴权/连通性检查与训练run分开，不能声称已训练。训练时显式online，缺凭据提前失败；离线模式用于本地验证。关键指标仍保存本地JSON，不让云端面板替代模型/数据hash、checkpoint和验收报告。
凭据存放远端用户配置目录、权限0600，运行时加载为SWANLAB_API_KEY，不进入项目文件、Git、报告或异常文本。只上传允许的配置和数值指标；不上传样本原文或权重。
