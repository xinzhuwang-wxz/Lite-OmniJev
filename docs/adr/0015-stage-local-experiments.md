# ADR0015：按阶段、按实测瓶颈自主纳入进阶优化与探索

状态：accepted，2026-10-15。用户本会话明确授权：“方案中的进阶优化与探索要按阶段做……探索性和组合创新的也要纳入考量在相应阶段，或者你发现的新的idea也可以去实验”。取代“第十一节探索默认不启用”；原HTML保留。

## 执行决定

负责人在各阶段主动审视原方案第十一节及新想法，不以成熟度标签排除实验；按当前瓶颈、收益和卡时排序。每阶段票内记录候选、触发证据与采用/暂缓原因，实际启动前在 `reports/explore/<编号>.md` 固定假设、对照、开发集、成功指标、失败/预算停止条件及端侧影响。先复用检查点/原始预测，再小批量A/B；有改善才扩大，成功后在阶段门复验，失败保留结论。不按每个想法另建票。

| 阶段 | 原方案候选与触发 |

## 预算与边界

按原方案11.6及各条目上限设天花板，同时给每次试验更小的实际卡时限额；H20实耗单列，不虚构换算成H100时。探索总量不超过主线实耗的30%，不把约24 H100时视为购买授权。当前先采用分钟级无重训对照；新资源、付费或突破现有预算仍需用户决定。

原模型、许可、概率语义、封存隔离与可复现证据保持。涉及新增分类头、基座替换、推理引擎定制或产品方向改变须另行明确决策，不能以实验授权自动修改产品硬约束。5b多步决策属于范围扩展，当前单步主线不因此自动启动；可以评估其必要性。实验失败不等于阶段质量门通过；质量目标如需调整必须另记原值、有效实测、新标准、理由和边界，不能仅将阈值贴合当前成绩。
