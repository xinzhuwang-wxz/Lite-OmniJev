# ADR 0010：用实测校准性能目标，限额优化后推进产品

状态：2026-10-14用户明确授权，取代早期“所有估计性能数字均不可调整”的执行规则。

## 授权与范围
用户原话：“有些性能是没做的时候估计的（整个方案都有这个问题），你要根据实际来调整标准，而不是一直钻牛角尖。补充一下这一点”。项目负责人可根据真实硬件、模型精度、工作负载和用户体验自主调整方案中的估计性能/资源目标，记录原目标、实测、理由、新验收和适用边界，无须为每次此类调整反复请求批准。

准确率/校准/概率语义、数据许可与隔离、模型基座、交付范围、真人证据和付费/资源操作权限不随此授权改变。原HTML不改写，旧失败报告不覆盖。没有实测时不能凭空给出新数字，不能把新的数值恰好设在已有最差结果上来制造通过。

## S0缓存决策
原≤2是预估性能目标，改为诊断目标；S0出口要求完成同协议真实native及网关cache-on/off、冷暖与重复测量，证明真实prefix命中、概率差严格<.001，并如实形成可复现的性能基线。该阶段不再以T10/T1≤2拦截训练。保留顺序与有界并发的区分；后者尚无完整网关GPU验收，不宣称发布就绪。

已有完整顺序证据：native冷比3.9318/3.9354，网关5.0202/5.0846；cache-off冷比分别9.9806/9.9930和10.0236/10.0255，实际KV复用288覆盖媒体265，四概率最大差2.365e-7。cache-on/off冷暖重复及网关预处理开销已保存。并发候选冷比最低约2.29，但继续FP32配置搜索收益不足，停止S0性能调参。FP32为数值参考，此结果不外推BF16生产吞吐或最终p95。

## 后续执行
S6原文本/截图/音视频时延与Q4内存等工程估计保留为目标，实际候选实现后一次代表性测试，再据用户体验、资源及收益明确修订；当前不凭空改数字或声称达标。每轮优化先写具体假设和时间上限，达预算或收益不足即保存结果并推进其它工作。FINAL验收以届时明确记录的实测标准为准，展示真实性能与限制，不能沿用原估计冒称通过。
