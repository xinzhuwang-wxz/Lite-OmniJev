# ADR0012：使用现成可靠真值，删除新增真人标注要求

状态：accepted，2026-10-15。用户明确：“意思放量还需要人标注吗，不是我们已经准备好的数据吗？我没有什么人标注的能力，这部分删了要不，就用能找到的数据”。取代ADR0011仅延期的决定及ADR0009的真人双标部分，原HTML作为历史需求保留。

## 首发合同
- 删除新增两名真人、12000次原始判断、真人身份/签认、Cohen κ≥.7和必须由用户提供外部gate账号的要求；S0、S4、FINAL均不再以缺人标阻塞。不安排付费标注/招聘/外包。
- 使用已准备或可取得、许可明确的原数据集gold/公开benchmark gold、可验证程序真值。原来源已有的人标可直接复用，不追加本项目双标。教师/LLM标签可用于允许的训练，不得冒充最终评测真值。
- 6000独立holdout（六cohort各1000）、各500dev的规模目标保留。现有开发基线不自动升级为holdout；实际数量/来源构建、原始family与媒体去重、数据质量和自动gate工程仍须验收。
- train/dev/calibration/holdout整family隔离、历史dev媒体排除、许可/revision/hash、固定分池、无holdout调参、阶段4/5/6只汇总结果均保留。自动gate独立作业读取封存内容，开发agent不读取内容/逐题答案；工程权限与日志拒绝测试由05交付，不宣称root同机chmod等于外部安全隔离。
- 人工κ明确not_applicable，不伪造1.0；替代证据是实际真值来源、标签完整性/合法性、固定规则、来源与媒体hash及池间无交集。来源不明或标签不可靠的题不用来充数。

## 阶段安排
S0完成技术基线后收口；S1–3可继续开发/训练。S1正式入训前冻结分池规则并预留未训练的holdout/calibration family，避免把所有来源先训完再找测试题。S4放量/封存评测前，s0:05交付真实现成gold封存数据与自动汇总gate，FINAL直接依赖该票。不能因没有新真人而阻塞，也不能把尚未构建的现成gold封存数据写成已经验收。

已下载的权重/媒体/数据是资产，现成gold可用性须按具体任务映射确认；已有S0六cohort3000题是开发集，不能兼作独立最终评测。未来发现某来源不足以满足目标时用实际来源证据调整选材，不通过模型成绩挑选测试题。

## 实现边界
configs/gates.json删除holdout_annotation_kappa，S4保留原模型质量/封存差/holdout_gate_pass，增加holdout_gold_provenance_verified。05由人类阻塞改为按阶段展开的工程票，负责可靠gold数据和自动gate，不引入手工账号前置。旧eval.sealed_gate/scripts.sealed_gate的v2双标canary保留为历史兼容工具，不是首发必走路径；新的实际gold gate由05实现，当前不冒称已实现。
