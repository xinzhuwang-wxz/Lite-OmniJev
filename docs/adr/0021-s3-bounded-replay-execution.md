# ADR0021：S3以有界均衡回放和固定质量门替代任意训练步数

状态：accepted，2026-10-15。依据用户授权负责人自主安排小批量迭代、实测有效才扩大、减少租卡时间，以及ADR0010的执行资源校准权限。此决定只调整S3训练执行预算，不改变基座、分池、质量阈值或正式评测要求，不代表S3已经通过。

原本地规格为300步smoke和10000次主训练曝光、lr1e-4。实际30步高学习率探针出现音频/视频及旧模态退化后已停止，没有为满足原步数继续训练。随后从已通过S2的v2 adapter暖启动，固定seed42、lr2e-5、r16/alpha32、每模态200行、100步×10累积，使用官方图像1120预算和16帧视频。

实际执行证据为reports/s3-stable-probe-train-001.json与reports/s3-training-exposure-audit-001.json：

- 100步、1000次总曝光，各模态200次；image199个原始family，其余每模态200个。不能称为完成原300步smoke或10000次曝光，也不能把失败run曝光加到当前权重上。
- step50有哈希绑定midway，step100有可恢复checkpoint；最终adapter为1bebae31309f799395d01499fb9deec5e44622599d0c082473ea8b5a014e5755。
- H20实耗843.25秒，峰值CUDA分配30144239616字节，128MiB准备缓存内完成全部1000例前向。首/末10步平均loss .722695→.207186仅为训练信号。
- 小筛查全部达扩展条件后，当前五模态dev500双遍结果为image82.0%、screenshot96.4%、text99.4%、audio80.0%、video63.6%；旧模态与S2相同，音视频原教师90%门保持。每组已核验完整记录/输入/权重/读出与两遍一致。

执行验收替换为：真实五模态均衡回放、曝光与midway可追溯、工程前向/缓存验证、固定五模态完整质量门及8/16帧对照。当前8帧对照、总门汇总和里程碑集成复核仍须完成；失败仍修复，不因该决定豁免。

原约24 H100时为估值，当前使用H20，不能把其小时数直接换算成H100或声称固定倍数提速。实测足够的候选不为凑步数重复训练；后续S4更高质量、封存、外榜及S5校准要求独立保留。本决定不授权付费/加租/大预算放量，也不证明正式服务性能或终局产品已达标。
