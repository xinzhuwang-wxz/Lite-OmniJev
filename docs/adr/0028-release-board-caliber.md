# ADR-0028: 发布榜口径收口(主表三榜 + 参照行)

日期:2026-10-18。决策人:用户("除了必须要用的(产品业务直接相关),剩下的尽量用对我们有利的,挑选一下";确认"按建议收口")。

## 背景

ADR0025 锁定了 SOTA 判定的四公开榜全集;ADR0026/0027 锁定"只引公开数、不为对照烧卡"。
release-002 发布物需要一张面向读者的主表;四榜并列会把口径不同的 MVBench 行抬到与产品
直接相关榜单同级的注意位。本 ADR 只定义**发布材料的表格口径**,不修改 ADR0025 的
"SOTA 一词判定全集"(仍须四对照全超,当前未达成,不称 SOTA)。

## 决策

**发布主表(产品业务直接相关,三榜)**
1. JevBench 231——决策产品主榜;我方 76.62 vs 教师公开 86.15(−9.5)照实披露。
2. MMAU test-mini 1000——发布形态主声明位:**模态路由形态(音频/文本路由基座)65.9 >
   教师公开 63.10**,为当前唯一超过最强可比对照的声明(OneJev-4B/27B 无音频塔,
   MMAU 格记"结构性不可评");候选全模态挂载 60.6 在同表如实并列。
3. Decision Index 公共子集(27/44)——产品最直接;教师公开发布数不在公共部分
   (其 87.57 为私有 Medium,引用必标"私有评测,不可验证");我方本轮实测后填入。

**参照行(口径不同,不作主声明)**:MVBench 九任务 1800(我方 48.5 vs 教师 53.09,
14 任务/2786,口径差双列标注)。

**不入发布声明表(维持既有决策)**:CLEVRER(方法试验场,模型卡附录可放,不称 SOTA);
DecisionBench Medium(私有);OneJev/Valen 自有私有集。

## 影响

- 模型卡、GitHub/HF README 的榜单表按本 ADR 组织;失败项(JevBench 缺口)照旧披露。
- Decision Index 公共子集打分列入本窗口执行(输入已 staged,官方 runner 在盒,<1 卡时)。
- 发布形态推荐 = 模态路由 adapter(音频/文本路由基座),与 MMAU 声明位一致;ADR0024 修订二已解禁。
