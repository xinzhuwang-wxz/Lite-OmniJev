# ADR-0026: 判定榜只用公开榜单

日期:2026-10-17 深夜。决策人:用户("自建榜单就不要了,不然还得找各种模型在其上跑;都用公开的榜单,也方便比较")。

## 决策

从 ADR0025 的判定榜集合中**移除第 5 项**("我们公开的多模态决策评测集")。判定榜收敛为四项公开榜:

1. Decision Index(含视觉榜,官方协议)
2. JevBench 231(公开协议 `scripts/s0_jevbench.py`)
3. MMAU test-mini 1000(S0 教师协议)
4. MVBench 决策子集九任务 1800(ADR0006)

其余口径不变:判定维度(准确率+可靠性+成本)、四对照(OneJev-4B、Valen-2B、Jev-Omni-12B、OneJev-27B)同协议同题我方实测全超才称 SOTA、CLEVRER 与封存池不用于 SOTA 声明。

## 理由

- 该榜从未建立("待定义"),移除零沉没成本。
- 自建榜需要其他模型在其上跑分才能横向比较,成本高且说服力弱;公开榜自带可比性。

## 影响

- 发布物模型卡按四公开榜报告;原第 5 项相关规划作废。
- 我方内部公开材料仍可附 CLEVRER 等试验场数据,但不计入 SOTA 判定(ADR0025 原文继续适用)。
