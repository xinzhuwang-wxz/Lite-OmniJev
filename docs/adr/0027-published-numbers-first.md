# ADR-0027: 对照以公开已发布数为准,不为对照烧卡

日期:2026-10-17 深夜。决策人:用户("榜单是人家已经发布的,我们就跑我们模型的相应内容补上去就行,不用跑别人的模型";"补完 1500 训练来不及了")。

## 决策

1. **我方模型**按各公开榜官方协议实测(MMAU/MVBench/JevBench/Decision Index),这是我们唯一要跑的分。
2. **对照模型**(OneJev-4B、Valen-2B、Jev-Omni-12B、OneJev-27B)优先采用**其已公开发布的分数**(模型卡/论文/官方榜);查不到的格子如实标"无公开数",不替别人跑。
3. 修订 ADR0025 的"四对照同协议同题全超":判定表述改为**"在四公开榜上超过对照的可比公开数"**,口径差异在差距表逐格标注(我方协议 vs 自报协议)。
4. D3P-600 为本期最终模型(1500 训练取消,留待下期);已启动的个别对照作业跑完即止,不再新开。
5. 协议差异风险留证:同一教师模型在自家协议 62.0 vs 我方协议 64.6(MMAU)——差距表引用自报数时须附此警示。

## 影响

- 省下全部对照烧卡(MVBench 约 3h/模型);Comparison 表 = 我方实测列 + 对照公开数列(标注来源与口径)。
- 若某关键格"无公开数"且对 SOTA 声明必要,是否例外烧卡由用户逐格决定。
