# ADR-0004：首发省略 AudioCaps 原媒体

日期：2026-10-14。状态：用户批准。

用户在本会话明确表示 AudioCaps 申请耗时、赶不上当前准备，并询问省略；本决策执行该范围调整，原始设计 HTML 保留。

首发阶段0–6不再以 AudioCaps 申请、审批或原音视频下载为开卡前置。已缓存的公开 caption/许可原料保留作历史审计，不进训练、不删用户资料、不代提交尚未提交的申请。

阶段3原定1万条 Clotho/AudioCaps 音频题，改以许可明确的 Clotho-AQA 样本为主，必要时由现有已验证 TTS 生成额外程序化真值题补足。原定0.8万 TTS tranche单独计数；不能将同一题重复计数以凑总量。构建时必须报告独立音频族数、题量、许可、train/dev/calibration/holdout隔离与真实/合成占比；不足仍是准备缺口，不能凭下载数量宣称达标。

音频质量门槛、教师同条件对照、MMAU评测与旧模态回归保持原契约。减少真实音频来源多样性的影响由阶段3实测判断；失败时优先查数据覆盖与处理器，不能为省申请降低门槛。AudioCaps未来恢复需记录许可和单独排期，当前不再列待用户授权。

本决策不免除DocVQA、Android SDK/NDK等其它来源的实际访问/使用手续，也不赋予任何受限数据商业训练或再分发权。
