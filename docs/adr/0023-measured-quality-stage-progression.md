# ADR0023：按真实完整训练与测量决定质量阶段推进

状态：accepted，2026-10-16，用户本会话明确决策。取代此前“任何原质量目标未达即不得进入下一阶段”的执行限制；不改历史结果，不把失败阈值改成通过。

## 用户决策与问题

用户要求选择最有潜力的方法先做完整训练、持续监控，指标下降时分析并接续；原方案质量估值可能不适合实际模型，经过实际尝试仍达不到时必须继续后续交付。此前S4已做完整video500/image500评测，但训练多为10–20步小试，不能据此称S4完整训练已完成或能力已饱和。

## 本轮实际执行

当前最有根据的主线是官方程序四分层CE。先完整覆盖已冻结1200条课程（600原视频、600回放），目标100步、1200实际draw；这只是当前课程全量，不冒称全部8299条视频或原方案大规模S4训练。保留f2db/rank16、原CE/LR/模板/帧数与推理引擎。已结束的step10/fullAdamW/RNG从同一轨迹恢复，检查点每5步保留；后续20/40/60/80/100分段监控和固定DEV50评测。一次有界窗口90分钟，包含本轮训练/评测调度；旧20分钟窗口文件与决定保留，新用户授权明确替代其继续运行限制。

小切片1–3题或轻微概率波动用于趋势分析，不再自动终止整个课程。非有限、来源/身份/数值契约失败、OOM、预算到期立即暂停；明确大幅质量退化也暂停分析并保留最佳检查点，不覆盖前一产物。不盲跑，不用未测检查点替换已测最佳模型。不另租卡、不续费、不操作开关卡。

## 阶段出口与质量披露

完整课程或有证据的提前终止后，对最佳候选与保留parent做同条件完整开发评测、旧模态/跨模态保留复核、必要独立封存汇总，记录实际质量、原目标、差距、数据/代码/模型/配置、耗时和采用理由。若剩余优化的实测收益与租期不支持继续，S4可记录为`closed_with_measured_quality_limitations`并进入S5校准、S6压缩/端侧及发布验收。

机器原始质量门仍输出原阈值下的真实passed/failed，历史目标与teacher分数保留；阶段进度与原始目标达成分开。不得声称原S4质量门通过，不通过校准/包装隐藏准确率差距，不冒称SOTA或超越Jev。后续质量目标同样以实测报告透明评估，采用与受限出口逐项记录，而非静默修改阈值。

概率语义、官方模板/单token映射、无新head/冻结基座、来源许可、train/DEV/私有池隔离、数值/打包一致性、鉴权及输入安全等正确性要求不因此放宽。最终发布必须带模型卡的已测质量与已接受局限；真实缺陷仍须解决，接受的质量局限不能冒充缺陷修复或质量达标。

## 本轮采用依据

原video500最佳354/500、image500为410/500，原视频91.374%和图像84.778%目标尚未达。当前300pair课程只覆盖严格in/out；分层课程补充事件运动、起止运动和碰撞程序，CPU容量、来源、隔离已核验。此前r64和条件排序的完整短试失败证据保留。本决策是用户授权的现实质量/进度权衡，不是从失败分数反推新门槛。
