# ADR0022：小样本筛选作为警戒与放量决策证据

2026-10-16用户明确授权：跨模态34/50与35/50的一题差异不应机械否决具有其他收益的候选，由负责人结合实际判断并鼓励创新。

决策：原有小筛选的计分和失败记录原样保留；其固定阈值属于内部实验筛选，不再自动否决更完整开发集评估资格。不把34改写成35，不事后改历史报告passed字段。新资格决定单独记录收益、退化、样本数、配对变化与预算；需要更广证据时可扩评。反复使用同一小切片会产生选择偏差，不以单题修复为优化目标。

当前例：coverage adapter0deef8cf…视频108/150相较首轮99/150增加9题，原cross34/50相较35/50减少1题（配对纠正1/退化2）。因此允许一次完整原视频dev500，再按完整跨模态来源分别与首轮对比。视频单作业≤600秒，跨模态每个来源/adapter作业≤600秒；先评估、再决定是否训练或扩量。已准备的alpha.5融合暂缓，不继续追逐50题阈值。

本授权不等于S4最终门槛已改变。最强教师比率、完整封存/开发差、外榜、S5/S6及最终产品验收仍按既定契约；不足与未测如实报告。封存仍不用于开发调参；不换基座/分类头/推理引擎，不扩5b或付费范围。

用户随后进一步强调机时紧张、全量必须途中监控、优先小步创新。执行调整：常规探索默认100题/单遍，跨模态每25题写公开dev进度，180秒硬预算；50/100/200节点依据配对变化与成本选择停止或扩大，不预先排长串全量。已完成video500保留证据，后继original cross500在31.28秒/18题主动中断，保留真实失败receipt并取消原保留候选500作业。新100题配对重新启动并独立记录，不能把取消说成自然失败。完整阶段验收仍只在候选冻结后执行。CPU准备与GPU串行作业并行，避免为了利用率运行无关实验。
