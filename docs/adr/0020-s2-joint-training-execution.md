# ADR0020：以已验证的联合训练替代S2分别训练的执行预算

状态：accepted，2026-10-15。依据用户要求负责人自主安排实测驱动的小批量迭代、减少卡时、无收益不重复全量，以及ADR0010资源估值校准权限。此决定调整训练执行方式；原S2质量门、开发集、双遍/反事实/旧模态要求全部保持。

原本地执行规格：图像、截图分别300步smoke；各自samples-seen=min(10000,5×池)，即图像6945次、截图2100次，50%保存midway。实际产品采用一个联合LoRA并回放文本，因此实际run已采用混合训练；不能把它们描述为完成了原来的两个独立smoke。

用真实保存的data.jsonl SHA、seed42、固定shuffle及modulo取样顺序重建曝光量，并校验最终adapter SHA，见reports/s2-training-exposure-audit-001.json：

| run | 步数 / 总曝光 | text / image / screenshot曝光 | image / screenshot唯一family | midway | H20实耗秒 |
|---|---|---|---|---|---|
| smoke-001 | 300 / 3000 | 1500 / 750 / 750 | 124 / 125 | 不设 | 814.19 |
| joint-001 | 1000 / 10000 | 8575 / 1073 / 352 | 1052 / 352 | step500 | 3114.77 |
| joint-v2-001 | 1600 / 16000 | 11962 / 3108 / 930 | 1341 / 420 | step800 | 4832.08 |

这些是不同run的曝光量，不能相加声称当前候选权重训练了2900步。候选v2明确绑定joint-v2-001最终adapter db45fb13…；其midway step800已由E01与最终权重作开发集对照，E02参数平均也已停止。v2完整覆盖当前image/screenshot全部训练family，变体不新增family。

执行验收替换为：一次300步三模态joint smoke（两媒体均实际参与、loss下降）+至少一套有可追溯曝光量和midway的joint主训练+完整质量门。smoke前/后30步平均loss .530433→.00000705；v2 .368851→.054548。loss仅是工程信号，不替代开发集结果。通过固定质量门决定推进，禁止为补旧清单强行重复两个smoke或补足任意曝光次数。

资源理由：单LoRA需要同时保留旧文本与两媒体行为；独立按模态跑足任意步数不能证明联合产品能力，旧池多条微调已无稳定收益。复用已有完整曝光/检查点/评测证据避免无意义重复耗卡；不声称相对于未运行的独立方案测得固定百分比节省。训练方式调整不免除失败门，1120候选仍须完整三模态双遍验收。
