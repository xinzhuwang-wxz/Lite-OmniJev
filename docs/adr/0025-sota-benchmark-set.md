# ADR-0025: SOTA 判定榜单锁定

日期:2026-10-17 晚。决策人:用户("跟跟我们产品提供服务相似的榜单来比……定下来不要以后偏移了";"要超过榜单上所有的作为 SOTA,包括教师"),负责人 SOTA冲刺2 与副手 SOTA冲刺1 对齐后落档。

## 背景

10-17 冲刺期间判定口径先后漂移到 dev150(CLEVRER exist 子集)、CLEVRER 四类题、项目内封存池分数,均不是原方案 §1.1 定义的榜单。本 ADR 锁定口径;此后任何"是否 SOTA"的结论只按本文件判定,修改须新 ADR 与用户决策。

## 决策

**判定榜(准确率,全部要求)**
1. Decision Index(含视觉榜):已准入子集按官方 decision-index 代码协议;新准入子集追加,不删已准入项。
2. JevBench 231(公开协议,`scripts/s0_jevbench.py`)。
3. MMAU test-mini 1000(S0 教师协议,两遍一致)。
4. MVBench 决策子集:S0 固定九任务 1800(ADR0006);若补全官方任务另记一行,不替换。
5. 我们公开的多模态决策评测集(随模型开源,一条命令复现)。

**判定维度**:准确率 + 可靠性(选项置换改答案率、正反问一致性、每模态 ECE、5% 错误率下可自动化覆盖率)+ 成本(各模态 p50/p95 时延、显存/内存、端侧可运行性)。

**对照对象**:OneJev-4B、Valen-2B(同尺寸);Jev-Omni-12B、OneJev-27B(上限)。用户口径:四者全部超过才称 SOTA。分数必须同协议同题由我们实测;他人自报的不同协议数字只作参考,不作判定。

**不是判定榜**:CLEVRER 四类题(视频训练/评测源与方法试验场)、项目内封存池分数(封存门槛,不对外)、dev150 / video500 / dev2 切片(调试与选型)。这些可以用于研发决策,不能写成"SOTA"。

## 影响

- 冲刺优先级由各判定榜实测差距决定;第一步是在 MMAU / MVBench 同题上实测候选与基座,并给 Decision Index 打分。
- 发布物模型卡按本 ADR 的表格报告,失败项照实披露。
- ADR0023 的阶段推进与原门槛记录方式不变;本 ADR 只锁定"SOTA"一词的口径。
