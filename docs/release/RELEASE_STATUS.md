## 使用边界

- 本次vLLM FP32/merged服务未激活绑定另一运行配方的温度，返回 `calibration: unfitted`。
- U属于内部读出；默认产品API只输出Choice/Score/yes-no概率与判断。内部一致性诊断需运维显式开启，不能当产品弃权功能宣传。
- 本地网关仅绑定127.0.0.1，不是公网生产服务；当前媒体采用受信服务端路径和SHA256，无公网文件上传/生产鉴权。
- 历史竞速GIF包括内部诊断信息与不同并发/缓存设置；不是当前默认配方p95/SLO，也不是八题共用一次前向。
