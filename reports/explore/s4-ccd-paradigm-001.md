# CCD:组合校准决策(Compositional Calibrated Decisions)范式 001

日期 2026-10-17,SOTA冲刺2。目标口径(用户):产品相关榜单超过所有条目(含教师)。本文是旗舰范式设计;数字门预注册,未实测前不作效果声明。

## 出发点(实测,见 s4-sota-takeover-diagnosis-001)
- 静态感知强(颜色/形状 F1 .97–.99),事件抽取弱(进/出/碰撞 F1 .09–.64)。
- 对教师 18 题差距中 15 题在 enter 题族;enter/先后/exit 可化归为逐帧"存在"判断。
- 执行器覆盖直答会输(胜 4 负 10):硬符号丢失了不确定性,错误的接地直接变错误答案。
- 产品原语本身就是**已校准的 yes/no / Choice 决策**。

## 范式一句话
难题不直接答:模型对共享的一次感知(缓存的媒体前缀)向自己发出大量**原子决策**(该帧有无黄色球体?该帧红方块在哪个格?两物体此帧是否接触?),每个原子返回校准概率;题面程序按**精确概率语义**组合原子(存在=1−Π(1−p),计数=泊松二项分布,先后=进入时刻分布的比较),输出仍是 Jev 式 Choice/Score/yes-no 分布。

## 三个维度的创新
1. **推理/架构:单次感知、多次决策**。媒体前缀只编码一次进 KV 缓存,每个原子只追加约 20 个 token + 单 token 读出;原子分解的时延近似线性于题面原子数而非帧数×媒体长度。复用项目已有前缀缓存测量能力。
2. **推理/输出:校准闭包**。组合是精确概率运算而非取 argmax 后执行,故原子校准 ⇒ 组合答案的分布可解释为校准分布;计数类 Choice 直接得到完整分布(泊松二项),不是单点。
3. **训练:原子银行 + 组合一致性双向蒸馏**。CLEVRER 训练注释给出每帧每物体真值 → 免费生成百万级原子决策样本(稠密程序真值监督,只训决策 LoRA,无新 head);同时把组合分布当软目标蒸馏回直答(产品快路径),并以直答×组合的分歧作困难样本挖掘——直答与组合互为教师,闭环收敛。

## 近邻与新颖性边界(诚实)
- NSVS-TL(ECCV 2024, arXiv 2403.11021):逐帧原子命题 + 概率自动机/时序逻辑做视频检索。相同:逐帧原子+概率组合。不同:我们原子由同一产品决策模型回答并经校准、输出为校准决策分布、原子模型以程序真值训练并与直答双向蒸馏、面向 QA 而非检索。
- DeepProbLog/Scallop:神经谓词+概率逻辑;我们的谓词是自然语言原子查询同一个冻结基座+LoRA。
- SQuINT(CVPR 2020)等子问题一致性:约束子问题与主问题一致;我们是概率组合的软目标蒸馏+校准闭包。
- 新颖性只主张在上述**组合闭环**(校准原子 → 精确组合 → 回蒸馏直答 → 共享前缀),不主张"分解"本身。

## 预注册判定门(dev 只调试;判定在未触碰的 CLEVRER 官方 validation 切片)
- G1 原子质量(零训练,基座/候选):逐帧存在原子 AUC ≥ .97;否则先训原子银行。
- G2 enter 族(PTR/CCD):在未触碰切片上 ≥ 教师同题正确率。
- G3 全 descriptive:≥ 教师,且 ≥ 已报告 CLEVRER descriptive 榜首(数值待副手核实表)。
- G4 explanatory/predictive/counterfactual:按官方 per-option/per-question 指标逐类对榜首;预测/反事实需要轨迹外推,先测原子位置精度再决定是否加入确定性物理推演模块(另立 ADR)。
- 任何门不过 → 记录证据,不移动门,转下一个备选。

## 执行顺序
1. PTR 探针(生成式逐帧列物体,进行中)→ 判断"化归"本身是否成立。
2. 原子 Noul 读出探针:同帧换成单 token 概率读出(校准原子),比对 PTR。
3. 构建 CLEVRER 官方 validation 未触碰评测(四类题,per-option 与 per-question),并对 D3P 与组合路径同协议实测。
4. 原子银行训练(G1 不过时)与组合一致性蒸馏。
