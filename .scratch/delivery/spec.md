# 单步多模态决策三档交付

Status: ready-for-agent

## Problem Statement
开发者需要低成本、可校准、可单卡和端侧复现的 typed decision 接口；完整设计尚待实验验证。
## Solution
按原设计训练0–6推进，统一数据/模板/读出/校准，以同一版本交付 API、单卡和E2B端侧包。
## User Stories
1. API开发者用Choice/Score/Noul获取答案分布、弃权概率、版本和时延。
2. 使用者上传支持的媒体并完成多题判断、失败恢复、curl重放。
3. 运维者一条命令启动单卡服务，能验证哈希并回滚模型/校准/配置整体版本。
4. 端侧使用者离线运行E2B并知道实测支持的模态、内存与时延。
5. 评测者可复现每阶段门槛、稳健性、对照和同200题跨运行时差异。
6. 负责人得到真实成本和限制，未通过指标不会被营销为SOTA。
## Implementation Decisions
沿用原方案主干/LoRA/词表读出，禁止推理侧定制；常规推进自动化，硬件采购与产品方向归用户。
## Testing Decisions
精确标准见项目验收契约及原方案；模型测试与软件测试分开，门槛缺证据保持blocked。
## Out of Scope
默认不做5b、探索项和未经授权的生产/付费运营；P4真实用户与观测窗口不能伪造。
## Further Notes
里程碑规格在前序通过后展开，本规格不提前冻结未知实验细节。
