# S0：可追溯基线与可信评测的下一批闭环

## Problem Statement
P0 十步训练及实际 GPU resume 已由主会话验证，但严格 HF/vLLM parity 尚阻塞，p0:04 未完成。此前 STATUS 的“0步/无卡”是旧快照，本规格只规划后续，不覆盖主会话事实。没有教师复现、真实多模态基线、原始概率对照、缓存时延与人工封存集一致性证据，不能开始 S1。

## Solution
建立有限的 S0 前沿票：教师来源及加载准入、同口径教师复现、100题跨模态读出、同图10题缓存、隔离人工标注交付。所有票显式依赖 p0:04；先准备规格不启动 S0 实跑。获得这些事实后再展开其余模型/模态基线票，并用独立集成票汇总全部阶段0门槛。技术 ready 标签只表示 brief 完整，不能越过依赖；人工票保持外部阻塞。

## User Stories
1. 作为实验负责人，我要在 P0 完整通过后启动 S0，避免基于未一致的读出训练。
2. 作为资产维护者，我要记录模型来源、revision、许可和逐文件哈希，保证加载的是核验资产。
3. 作为教师维护者，我要区分资产准入与效果准入，避免下载成功等同可用教师。
4. 作为研究者，我要冻结MMAU精确split与±2pp复现，以及ADR-0006公开9任务MVBench独立baseline。
5. 作为训练者，我要原标签/程序真值优先，且不接触禁止的 Jev API、JEV-27B/VL 权重及标签。
6. 作为服务使用者，我要完整答案和 U 的原始概率，避免采样或 top-k 伪造分布。
7. 作为研究者，我要同权重和相同处理配置的100题对照与重复运行证据。
8. 作为多题调用者，我要同图10题总时延不超过单题2倍，而非仅看到缓存命中。
9. 作为 gate 管理者，我要内容不可被开发 agent 读取的封存区与最小汇总输出。
10. 作为评测负责人，我要真实独立人工标注、一致性和裁决记录，不能拿模型标签冒充人标。
11. 作为研究者，我要每模态500题开发集和1k题人工封存集，按 sample family 隔离。
12. 作为后续训练者，我要五模型同条件基线、token预算、时延和完整来源证据。
13. 作为交付负责人，我要缺失门槛被标 blocked，且不因某个工具测试通过而提前放行。
14. 作为预算负责人，我要实际耗时、资源与费用记录，任何额外付费或放量另获授权。

## Implementation Decisions
- 复用现有资产 manifest、数据契约、共享模板、答案 token 映射、概率归一化、指标与 gate、P0 parity 命令。缺失的多模态 processor 输入路径按真实垂直切片补齐，不重写推理引擎。
- 教师自带 head 仅限独立教师适配器；学生 E4B/E2B 仍冻结主干，只训决策 LoRA，不增加分类头。
- head.pt 不进入正常推理加载路径。固定来源并审计后，在隔离无网络转换边界使用限制型 tensor-only 读取，验证键、shape、dtype、数值与输出等价，再仅加载 safetensors。不能满足边界则停止；需要政策例外必须 ADR 与授权。
- 模型许可、上游来源声明、数据许可和标签生成来源分别审计；不明来源不进训练，研究数据隔离。允许的 OneJev 与禁止的 JEV-27B 不混同。
- 用户批准ADR-0006后的阶段0目标：教师MMAU63.1±2pp、MVBench固定9任务/1800题真实独立baseline、重复一致、100题概率差严格<1e-3、同图10题/单题≤2、人工κ≥0.7、基线表完整。
- 基线范围为 Jev-Omni-12B、OneJev-4B/27B、E4B/E2B 零样本；明确不支持的模态，不伪造分数，任何影响原范围的缺口保留阻塞与决策。
- 当前只细拆确定的前沿；模型可用性、媒体与预算实测后由扩展票生成剩余 session-sized 基线票，并补全集成依赖。

## Testing Decisions
以命令→真实资产/输入→汇总报告和现有 HTTP 公共接口为主要测试边界，复用现有 pytest 的拒绝路径与指标/gate 测试。测试缺许可、hash错配、缺答案token、采样分布混入、split/分母错配、未签认或伪造人标证明均不能放行。CPU/合成测试只证明工程行为；真实 GPU、媒体、重复运行、时延和人工κ分别留实际证据。封存访问控制用非封存 canary 测试，agent 不读取封存内容。

## Out of Scope
S1训练、阶段5b/探索、生产发布、默认新增付费、换主干、改门槛、agent生成人工真值、提前细拆S1–S6。已有 s0-data:01 的 CLINC 映射不复制，本规格保持其独立票。
